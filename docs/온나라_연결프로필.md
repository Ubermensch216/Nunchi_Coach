# 온나라 연결 프로필

갱신일: 2026-10-07 · 현재 상태: **실제 기관 연결 미확보·미검증**. 개발 가능한 공통 수집 엔진과 합성 연결부를 구현했다.

| 항목 | 상태 |
|---|---|
| 실제 기관/온나라 버전 | 미확보 |
| 접속 브라우저·인증·시험 환경 | 미확보 |
| 작성자 검색 필드·소속 이력·검색 상한 | 미확보 |
| API/화면 다운로드/내보내기 방식 | 미확보 |
| 실제 본문·붙임·메타데이터 표본 | 미확보 |
| 합성 연결부 | `FixtureConnector`, `fixture-v1` |
| 합성 문서 범위 | ID 기반 작성자·기간·소속·상태, 작성/기안/공동기안 역할 |
| 수집 엔진 | 전체 페이지·본문/붙임 큐·해시·실패·인증 대기·재개·manifest |
| 로컬 분석 연결 | ODT/붙임 파싱, 문서 FTS와 청크 준비 |

합성 연결부의 `simulation=true`, `live_verified=false`가 manifest와 실행 결과에 유지된다. 이름이 같은 작성자를 하나로 합치지 않는다. 전체 건수가 없거나 검색 페이지가 반복되면 범위 전체 수집을 완료했다고 표시하지 않는다.

실제 연결부는 `app/connectors/onnara/contract.py`의 인터페이스를 구현한다. 기관에서 확인한 작성자 검색·목록·메타데이터·본문/붙임 다운로드 방식으로만 연결하며 전임자 계정·인증정보를 전제로 두지 않는다. 접속 사양을 얻으면 작은 범위의 검색→파일 확보→메타데이터 대조를 먼저 검증한다.

앱에는 수집을 실행하는 화면도, 실환경 연결 화면도 없다. 합성 수집은 명령줄 도구(`app.tools.onnara_demo`)로만 실행하며 방법은 루트 README 8-5절에 있다. 2026-10-09부터 노트북의 `+ 자료 추가 → 온나라 수집본 가져오기`로 **이미 내려받아 둔 수집 폴더**를 읽어 노트북 자료로 연결할 수 있다(`app/core/onnara_import.py`). 수집 폴더를 읽기만 하며 온나라에 접속하지 않는다. 합성 수집본으로만 확인했다. 공식 출처 메타데이터는 `app/core/provenance.py`가 프로젝트 DB에 등록하며 질문 화면의 인용·근거에 표시된다.

업무 복원(C01~C08)은 구현됐다. 수집본은 업무 항목의 근거 순서에서 앞서고(값의 승패에는 쓰지 않는다), 수집을 아직 하지 않은 프로젝트에서는 공백의 ‘다음 행동’이 온나라 수집을 실마리로 안내한다. 남은 것: ‘지금 할 일’ 카드와 문서 화면에 문서번호·상태 같은 공식 출처를 표시하는 것, 내용이 다른 로컬 초안과 등록본의 버전 연결, 인계 묶음을 받은 쪽으로 출처 표를 옮기는 것. 실제 기관 연결(O02)이 계획서 기준 P0이며 미완료다.
