# 온나라 연결 프로필

현재 상태: **실제 기관 연결 미확보·미검증**. 개발 가능한 공통 수집 엔진과 합성 연결부를 구현했다.

| 항목 | 상태 |
|---|---|
| 실제 기관/온나라 버전 | 미확보 |
| 접속 브라우저·인증·시험 환경 | 미확보 |
| 작성자 검색 필드·소속 이력·검색 상한 | 미확보 |
| API/화면 다운로드/내보내기 방식 | 미확보 |
| 실제 본문·붙임·메타데이터 표본 | 미확보 |
| 합성 연결부 | `FixtureConnector`, `fixture-v1` |
| 합성 문서 범위 | ID 기반 작성자·기간·소속·상태, 작성/기안/공동기안 역할 |
| 수집 엔진 | 전체 페이지·본문/붙임 큐·해시·실패·인증 대기·재개·manifest |
| 로컬 분석 연결 | ODT/붙임 파싱, 문서 FTS와 청크 준비 |

합성 연결부의 `simulation=true`, `live_verified=false`가 manifest와 실행 결과에 유지된다. 이름이 같은 작성자를 하나로 합치지 않는다. 전체 건수가 없거나 검색 페이지가 반복되면 범위 전체 수집을 완료했다고 표시하지 않는다.

실제 연결부는 `app/connectors/onnara/contract.py`의 인터페이스를 구현한다. 기관에서 확인한 작성자 검색·목록·메타데이터·본문/붙임 다운로드 방식으로만 연결하며 전임자 계정·인증정보를 전제로 두지 않는다. 접속 사양을 얻으면 작은 범위의 검색→파일 확보→메타데이터 대조를 먼저 검증한다.

현재는 UI의 실환경 연결 화면을 제공하지 않는다. 합성 수집의 실행 방법은 루트 README에 있다. 공식 출처 메타데이터는 `app/core/provenance.py`가 프로젝트 DB에 등록하며 질문 화면의 인용·근거에 표시된다. 업무 복원 카드에 보여 주는 UI는 후속 C 작업이다.
