## 검증

핵심 변경 검사 72개가 통과했다. 최초 전체 회귀에서는 921 통과·2 실패·5 건너뜀이 나왔다. 실패 2개는 연도 범위 질문을 쓰면서 연도 메타데이터를 채우지 않은 기존 테스트 자료였으며, 해당 자료에 명시 연도를 설정해 기존 인용·검색 목적을 유지했다. 수정된 RAG와 수집 재개 검사 36개가 통과했고 전체 회귀를 다시 실행 중이다.

합성 CLI 실행은 작성자 `author-001`의 문서 27건·본문/붙임 81개를 수집하고 파싱 81 성공·0 실패를 확인했다. manifest의 `simulation=true`, `live_verified=false`와 완전성 결과가 유지됐다. 잠금 의존성 비교도 차이 없이 통과했다. 실제 AI 모델·기관 온나라·배포 실행물의 검증 완료를 선언하지 않는다.

검사 자료:

- `.test_runs/full-results.txt`, `full-results.xml` — 최초 전체 회귀.
- `.test_runs/full-results-final.txt`, `full-results-final.xml` — 최종 전체 회귀.
- `.analysis_audit/onnara-source` — 합성 원본, `.analysis_audit/onnara-collected/manifest.json` — 수집·출처·파일 검증 결과.
- `.analysis_audit/onnara-project/project.db` — 수집 파일의 파싱·FTS·청크 연결 검증.
