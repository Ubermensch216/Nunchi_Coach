# 챙길 일·보고서·저장 및 이동 기능 정리

기존 업무 홈 오른쪽에 세 버튼이 서로 다른 범위의 기능으로 모여 있었다.
각 버튼의 이벤트 처리와 화면, 생성 데이터와 실제 내보내기 경로를 확인한 뒤
상단 메뉴와 인수인계 화면으로 재배치했다.

| 이전 버튼 | 실제 기능 | 변경 위치 |
| --- | --- | --- |
| 챙길 일 | 과거 반복업무 기반 제안, 진행 중인 수행 건, 빠진 단계 후보, 승인 대기 및 준비 작업 | 상단 **챙길 일** 메뉴. 건수와 기존 수행 동작 유지 |
| 보고서 만들기 | 업무 설명·반복 주기·과거 문서 처리 순서·대표 문서·자료 위치·확인 상태를 Markdown으로 내보냄 | **인수인계 > 인수인계 매뉴얼**. 업무 안내와 같은 내용의 미리보기·파일 저장으로 보완 |
| 저장·옮기기 | 시점별 업무 복원본·검토 인계본 보관, 저장본 문서 내보내기, ZIP 인계 묶음 내보내기·가져오기 | **인수인계 > 기록 보관·이동**. 별도 창 없이 메뉴 안에 표시 |

## 매뉴얼과 저장본의 차이

- **인수인계 매뉴얼**: 현재 프로젝트의 전체 업무를 후임자가 읽을 문서로 묶는다.
  업무 개요·일정·준비물·절차·산출물·제출처·건별 현황·주의사항·과거 사례·근거를 포함한다.
  개조식·표를 사용하고 자료 값·확인 상태와 일반 준비 제안을 구분한다.
  새로운 사실을 생성하거나 원문을 수정하지 않는다. 미리보기와 같은 내용의 `.md` 파일을 저장한다.
- **저장본**: 특정 시점의 업무 지식·절차·확인 상태·수행 기록을 보관한다.
  현재 업무가 바뀌어도 옛 저장본의 내용은 바뀌지 않는다. 문서 내보내기도 선택한 저장본에서 생성한다.
- **PC 이동용 묶음**: 업무 기록과 인용문을 다른 PC에서 이어받는 `.zip` 파일이다.
  원문 파일은 포함하지 않으며, 원문을 포함한 전체 프로젝트 백업으로 표시하지 않는다.
  가져올 때 기존의 수동 수정·수행 기록을 보호하는 병합 동작을 유지한다.

## 화면과 동작

상단 메뉴 순서는 **업무 / 챙길 일 / 노트북 / 인수인계**다.
기존 단축키 `Ctrl+1`(업무)·`Ctrl+2`(노트북)는 유지하고,
`Ctrl+3`(챙길 일)·`Ctrl+4`(인수인계)를 더했다.
자료 폴더 없이도 인수인계 메뉴에서 저장본을 가져올 수 있다.
검토 인계본 발행 후 안내 문구도 새 메뉴 경로를 가리킨다.

기존 보고서 생성 함수·저장본 형식·파일 가져오기 호환성은 유지한다.
기존 프로젝트를 변환하거나 저장된 복원본을 다시 작성하지 않는다.

## 검증

보고서·저장본·전달 묶음·원문 덮어쓰기 방지·메뉴 전환·미확인 표시를 시험했다.
추가 시험은 현재 매뉴얼과 과거 저장본의 분리, 미리보기와 저장 파일의 일치,
열람만으로 저장본을 만들지 않는 점, 빈 프로젝트에서의 진입을 확인한다.
