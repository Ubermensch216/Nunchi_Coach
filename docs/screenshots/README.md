## 2026-10-20 Windows 글꼴 엔진·벡터 확대 비교

41번은 기존 DirectWrite 렌더링, 회색조 FreeType 렌더링, 기존 PNG 3배 확대, 72px 실제 재렌더링을 비교한다. 42번 SVG는 글자를 실제 벡터 path로 저장한 예시이며 비트맵이 없다. 43~45번은 이전과 같은 합성 DB 사본을 Windows FreeType 엔진·숨겨진 Qt 위젯으로 렌더링한 홈/업무 안내/어두운 테마·큰 글자 화면이다. 38~40번 이전 엔진의 기록은 유지한다.

별도 Windows 프로세스의 샘플에서 RGB 색 번짐 픽셀이 1,578개에서 0개로 감소했다. Windows 플랫폼의 배율 100/125/150%와 글자 크기 3단계도 조합해 확인했다. 실제 모니터의 확대 도구나 원격 화면 보간을 검증한 것은 아니다. 자세한 조건과 한계는 [폰트 벡터 렌더링 검토](../폰트_벡터렌더링_검토_2026-10-20.md)에 적었다.

## 2026-10-20 근거 탭

[53-work-evidence-tab.png](53-work-evidence-tab.png)는 합성 프로젝트 DB 사본의 행정사무감사 업무를 1280×900·밝은 테마·보통 글자로 렌더링했다. ‘매뉴얼’ 오른쪽의 ‘근거’ 탭이 본문 전체 폭을 사용하며, 별도 오른쪽 패널과 상단 근거 버튼은 없다. 업무명·반복 주기·매뉴얼의 연결 근거를 모으고, 본문 근거 링크는 이 탭의 해당 항목으로 이동한다. 파일명·원문 위치·인용·변경된 원문 경고와 원본 열기 기능은 유지한다.
