# 남은 검증과 후속 단계

2026-10-10. 개선 전체의 완료 선언이 아니다. 다음 항목은 구현·검증 범위를 구분해 관리한다.

## 다음 착수 우선순위

1. **대표 업무 정의·평가셋 확정(P1 선행).** 업무 유형과 연도별 수행 사례, 다중 업무 문서의
   정답 단위를 기관 담당자와 정한다. 독립 라벨과 계열 단위 보류 세트로 정밀도·재현율을 잰다.
   7문서 합성 반례로 95% 목표 달성을 주장할 수 없다.
2. **형식별 추출 계측(P0 잔여).** PDF 텍스트 없는 페이지, HWP 미리보기·복잡한 표,
   HWPX 병합 구조, Excel 실제 읽은 셀/시트와 생략 범위를 구조화한다. OCR 및 구형 DOC/XLS/PPT
   처리 범위는 실문서와 설치 가능한 로컬 도구를 검증한 뒤 확대한다.
3. **행정 관계와 다중 업무(P1).** 전체 조각의 가중 평균도 한 문서 안 여러 업무를 하나의
   벡터로 압축한다. 사업·문서번호·행정행위·참조 관계를 후보 검증에 결합해야 한다.
   동일 양식의 다른 사업과 이질 서식의 같은 업무를 대표 평가에 반드시 포함한다.
4. **확신 보정·비업무 자료(P1).** 단일 문서는 낮은 확신 후보이며 진짜 업무라는 판정이 아니다.
   참고자료/개인자료가 후보를 늘릴 수 있다. 현재 high/medium/low는 보정된 확률이 아니다.
5. **대규모 성능·운영(P2).** 1만 파일 장시간 측정, 네트워크 공유 장애, 전체 디스크 한도,
   조사 이력 보관기간, Windows 번들 검증과 실제 기관 파일럿이 남아 있다.

## 현재 동작의 구체적 한계

- 완성되지 않은 조각 색인은 대표 벡터로 대체한다. 모든 문서를 전체 본문으로 분류했다고
  표시하지 않는다. 파싱 자체에서 빠진 내용은 어떤 색인으로도 복원할 수 없다.
- 작명/일치성 모델은 예산 안의 대표 발췌만 읽는다. 문서 전부나 모든 문서를 검토하지 않는다.
- 파일명 첫 토큰의 낮은 확신 보완 묶음은 기존 동작으로 남아 있다. 해당 경로를 근거 없는
  확정 분류로 해석하면 안 된다. 다중 신호 검증으로 대체하는 것은 후속 평가 대상이다.
- 1~2건 업무는 개별 후보로 노출된다. 같은 업무의 두 문서가 각각 후보가 되는 과분할은
  대표 평가와 사용자 병합 흐름으로 확인해야 한다.
- 과거 사용자 해제 기록이 있는 문서는 자동 재배정하지 않는다. 자동 탐색을 다시 허용하는
  별도의 해제 이력 재설정 UX는 없다. 사용자는 기존 수동 배정 기능을 사용할 수 있다.
- 조사에서 제외한 기존 문서의 분석 이력은 보존된다. 제외 설정을 기존 검색 결과에서도
  즉시 숨기는 범위 정책은 별도 확정이 필요하다. ‘원본 삭제’와 혼동해 이력을 지우지 않는다.
- 재색인 또는 원문 변경으로 조각이 사라지면 이전 분류 근거는 재확인 표시된다. 기존
  노트북 인용 아카이브와 분류 근거를 자동 재연결하는 것은 아직 하지 않는다.
- 진단의 모델 발췌 제공 문서 수는 현재 배정된 업무의 유효한 분류 근거 범위다.
  보류·반려된 후보까지 포함한 전체 모델 호출 이력·비용 집계는 후속 과제다.
- 법령·지침의 현행 효력과 행정 절차의 공식성을 자동 보증하지 않는다. 기존 명시 근거와
  과거 수행 사례의 구분은 유지하며 도메인별 실제 정답으로 검증해야 한다.
- 원자적 내보내기와 경로 재검증은 기존 구현을 유지했다. 악의적인 동시 정션 교체까지
  Windows 커널 핸들 수준에서 차단했다는 주장은 하지 않는다.
- 기존 프로젝트를 원본 자료원 안에 만드는 설정 자체를 금지하는 정책은 도입하지 않았다.
  새 진단은 프로젝트 DB에 저장되므로 운영 시 프로젝트 관리 폴더와 자료원 분리가 필요하다.
- 모델 호출 취소는 보존되지만 생성 검토가 많으면 업무 발견 시간이 길어진다. 모델 입력
  캐시와 군집 단위 증분 재검토는 후속 최적화 대상이다.

## 실제 자료 검증 시 필요한 입력

원본을 외부에 전송하지 않는 로컬 환경, 형식·업무 크기·연도별 대표 자료, 담당자가 확인한
업무/문서 배정/핵심 사실/절차 정답이 필요하다. 실제 자료가 없으면 없는 상태를 유지하며
가상 수치나 합성 결과로 인수 기준을 채우지 않는다.
