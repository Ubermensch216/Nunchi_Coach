# 업무 안내의 개조식·시각화 및 색상 통일

업무 안내와 매뉴얼의 주 화면을 핵심 항목, 표, 단계별 흐름도로 변경했다.

| 내용 | 표현 |
| --- | --- |
| 업무 개요 | 목적·대상·기간·내 역할을 항목별 표로 정리 |
| 처음 맡으면 할 일 | 대조 자료·확인 항목·진행 상태를 개조식으로 안내 |
| 일정 | 반복 시기·감사 대상 기간·감사 실시 기간·마감을 표로 구분 |
| 수행 절차 | 번호·화살표와 시점·할 일·산출물을 함께 표시 |
| 결과물·제출처 | 작성할 결과물과 전달 대상을 표로 분리 |
| 근거와 예외 | 기존 근거 버튼, 확인 상태, 충돌·재확인 표시 유지 |

흐름도는 Qt 텍스트·벡터 요소로 그린다. 글자 확대와 다크 모드에서도
선명하며 내용을 선택·복사할 수 있다. 선후관계가 확인된 수행 단계 또는
준비 순서 제안에만 화살표를 표시한다. 준비 제안은 해당 기관의 확정 절차와 구분한다.

긴 다음 행동은 핵심 정보와 참고할 과거 단계로 정리하고, 전체 설명은
‘상세 안내 펼치기’에서 읽을 수 있다. 원문 값·상태를 저장하거나 수정하지 않는다.

## 색상

테마마다 5개 기본색을 사용하며 업무명·ID에 따른 색상 구분을 제거했다.
카드, 월별 표시, 노트북 표지, 표와 흐름도에 같은 강조색을 적용한다.
기존 노트북 표지 색상 변경 메뉴도 제거했다. 저장된 노트북 자료에는 영향이 없다.

| 역할 | 밝게 | 어둡게 |
| --- | --- | --- |
| 카드·주 화면 | `#FFFFFF` | `#202F40` |
| 보조 배경 | `#F1F4F8` | `#17212D` |
| 경계선 | `#CAD4E0` | `#3C5067` |
| 본문 | `#344256` | `#D9E3EE` |
| 강조 | `#365F86` | `#92B1D1` |

확인·주의·오류는 배지 문구·기호와 함께 표시한다. 본문·강조·버튼 글자의
배경 대비는 테스트에서 4.5:1 이상임을 확인했다.

## 검증·화면 기록

업무 안내·매뉴얼, 근거, 과거 사례, 노트북, 타이포그래피·화면 스모크 테스트를 실행했다.
추가 테스트는 사실·날짜·충돌 상태 보존, 선후관계가 없는 단계의 화살표 제한,
5색 팔레트, 상세 안내 펼치기, 작은 창·큰 글자의 줄바꿈을 확인한다.

캡처는 합성 자료를 실제 Qt 화면에 표시한 결과다. 사용자 프로젝트를 변경하지 않았다.
UI 변경은 앱 재실행 후 적용되며, 이 변경만을 위해 자료를 다시 분석할 필요는 없다.
