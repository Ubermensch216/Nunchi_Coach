# 규제개혁 비교연구 P1-1 건 단위 구현 기록

작성일 2026-10-14 · 근거 상세개선계획서 4.1(WorkCase)·5장 · 앞 단계 [P0 구현 기록](규제개혁_비교연구_P0_구현기록_2026-10-14.md)

P0는 남의 건의 칸을 업무 값으로 **읽지 않게** 막았다. P1-1은 그 행들을 버리지 않고 **건**으로 세운다. 규제 개선 건의 한 건, 개선 사례 한 건, 정비 대상 규제사무 한 건이 부서 목록 → 우리 기관 목록 → 상급기관 취합표 → 부처 검토결과로 이어지는 것을 한 건으로 잇고, 자료가 말한 데까지만 진행을 매긴다.

## 1. 구조

| 단위 | 저장 | 비고 |
|---|---|---|
| 업무 | `tasks` (그대로) | 반복하는 책임 |
| 회차 | `work_cases` (그대로) | 업무 × 연도 수행. 알림(`proactive.recommend.case_of`)이 "그해 첫 건"으로 조회하므로 개별 건을 넣지 않았다 — 넣으면 시기 알림이 꺼진다 |
| **건** | `matters` (신규) | 식별자는 `관할|정규화한 제목`. 행 번호가 아니다. 사람의 진행·메모·제외 표시 칸을 따로 둔다 |
| **건의 등장** | `matter_sources` (신규) | 문서·시트·**행 번호**, 우리 목록/취합표 구분, 회차, 그 행의 주요 칸 |
| 목록 읽기 기록 | `matter_scans` (신규) | 문서 판(해시)별 결과: 읽음 / 건 목록 아님 / 열 수 없음 / 분석 뒤 바뀜, 우리·다른 기관 행 수 |

표는 `app/db/matter_schema.sql`에 두고 `Database.init()`이 매번 붓는다(전부 `IF NOT EXISTS`, 스키마 버전 변경 없음). PyInstaller 묶음 목록에 추가했다.

## 2. 읽는 법 (`app/core/matters.py`)

- **원본을 다시 연다.** xlsx 파서는 행을 탭으로 잇고 끝 빈칸을 지우며 셀 안 줄바꿈을 그대로 둔다. 저장된 본문으로는 행·칸 경계를 되살릴 수 없다. 그래서 문서의 저장 해시와 원본 파일의 SHA-256이 같을 때만 읽기 전용으로 연다. 다르거나 열 수 없으면 읽지 않고 `changed`/`unreadable`로 남기며, 전에 세운 건은 지우지 않는다. 같은 판은 다시 열지 않는다.
- **건 목록의 조건**: 머리 행에 제목 칸(`제목`·`과제명`·`사례명`·`안건명`·`건명`)과 시군구 칸이 함께 있어야 한다. `규제사무명`은 정비 칸이 함께 있을 때만 건이다(등록규제 대장은 건 목록이 아니다). 시군구 칸이 없으면 누구의 건인지 모르므로 건을 만들지 않는다. 병합된 시군구 칸은 아래 행으로 이어 쓴다.
- **우리 기관**: 사람이 정한 값(`own_locality` 메타)이 먼저, 없으면 파일 이름 괄호의 시군구(`…(가나구).xlsx`)가 3번 넘게 나온 곳. 정하지 못하면 건을 하나도 만들지 않는다.
- **우리 행만 건이 된다.** 다른 기관의 행은 몇 행인지만 센다(참고 사례).
- **같은 건**: 같은 관할에서 띄어쓰기·괄호·기호를 뺀 제목이 같거나 매우 비슷하면(0.92) 같은 건이다. 그보다 다르면 합치지 않고, 다음 행동에서 "제목이 바뀌어 따로 잡혔을 수 있는 건"으로 사람에게 묻는다.
- **진행 단계**: 우리 목록에만 있음 → 상급기관 취합표(서로 다른 기관 3곳 이상)에 있음 → 회신 칸(`부처의견`·`검토결과`·`수용여부`·`개선여부`·`실적인정 여부`…)에 글이 있음. 회신 글에서 수용·부분 수용·불수용·검토 중을 가르되, 못 가르면(`5. 기시행`, `6. 타부처 소관`) 글만 보인다. 우리가 적은 정비 판단(`정비대상 여부`, `정비내용`)은 회신이 아니다. **개선 완료·시행은 자료로 정하지 않는다** — 사람의 진행(`submitted`…`implemented`, `closed`)으로만 적는다.
- 부서 칸이 없으면 부서가 낸 목록의 파일 이름(`…목록(토지정보과).xlsx`)에서 주관 부서를 읽는다.

## 3. 보이는 곳

| 곳 | 내용 |
|---|---|
| 업무 매뉴얼 `건별 현황` 구획 | 요약(우리 건 수 · 회신이 이어진 수 · 다른 기관 행 수) + 건마다 "회차 · 제목 — 주관 · 소관" / 진행. 근거는 `'시트' N행`. 15건 넘으면 나머지는 결과 초안으로 |
| 다음 행동 `[건별 진행 확인]` (check) | 가장 최근 회차의 건 가운데 결과가 이어지지 않고 사람도 진행을 정하지 않은 것. 건 종류마다 기다리는 결과가 다르다: 건의 → 부처 회신, 사례 → 선정·결과 통보, 정비 → 자치법규 개정·등록 반영, 안건 → 심의 결과 |
| 결과 초안 `## 건별 현황` | 회차·건·주관/소관·진행·근거 표 |
| 업무 복원 단계 알림 | "우리 기관의 건 N" |

## 4. 실제 스냅샷 사본 측정

조건은 P0와 같다(백업 사본, 기준일 2026-10-14, 규칙만). 원본 파일은 `E:\[규제개혁]`에서 읽기 전용으로 열었다.

- 우리 기관 자동 판정: 사하구. 표 계산 문서 85건 중 건 목록 32건을 읽었고 53건은 건 목록이 아니었다(담당자 명단·실적표·대장 등). 열지 못한 문서 0건. 소요 12.9초(첫 실행, 이후 같은 판은 건너뜀).
- **건 30개**(우리 행 67개), 다른 기관 행 **4,810개는 건수로만** 셌다. 건이 붙은 업무 9개.
- T09 규제혁신 과제 제출: 2025 상반기 건의 6건(토지분할, 견인 대행 요건, 공원 활용, 산단 홍보관, 도시민박 요건, 공장 조경)이 업무매뉴얼 사례 C의 F0279 4~9행과 일치한다. 부서 목록 → 우리 목록 → 부산 취합 → 전국 취합 → 부처 검토결과로 이어졌고, 회신 칸에서 `3. 수용불가`(2건), `6. 타부처 소관`, `5. 기시행` 등을 읽었다. 도시민박 요건 건은 회신이 이어지지 않아 확인 요청이 나오며, 제목이 바뀐 "규제가 발목잡은 외국인 도시민박업 개선 제안"(회신 `1. 수용`)이 같은 건인지 묻는다.
- T03·T08 2024 상반기 "해체 및 재활용 선박 취득세 면제": 주관 세무2과, 회신 `7. 검토제외`.
- T04 규제해소, T11 입증책임제, T07 성과평가, T15·T32 사례 업무에도 각 회차의 우리 건이 붙었다.
- 2023 분기별 검토결과(1,039행)와 2024 하반기 협의목록(945행)에는 사하구 행이 실제로 없음을 원본에서 확인했다.

## 5. 시험

- `tests/test_matters.py` 20건: 머리글 판정, 회신 갈래, 우리 기관 판정(정하지 못하면 건 없음), 네 목록을 한 건으로 잇기와 단계, 다시 세워도 같은 id·같은 판 건너뛰기, 분석 뒤 바뀐 원본은 읽지 않고 이전 건 유지, 사람의 진행·메모 보존, 매뉴얼·다음 행동·초안, 제목이 바뀐 쌍 안내(합치지 않음), 정비 건은 회신이 아니라 정비 결과를 기다림. 실제 xlsx를 임시 폴더에 만들어 읽는다(지어낸 이름).
- 전체 회귀: 6장.
