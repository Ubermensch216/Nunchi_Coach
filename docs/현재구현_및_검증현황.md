## 3. 화면에서 달라진 것 (참조 프로젝트 대비)

- 분석 단계에 **‘업무 복원’** 이 더해졌다(처리 순서 파악 다음).
- 질문의 근거 카드와 원문 정보줄에 온나라 수집본의 문서번호·상태·본문/붙임이 표시된다(수집본이 있을 때. 합성 자료는 합성으로 표기).
- 설정 → 시스템에 **‘오픈소스 고지’** 가 생겼다.
- 생성 실패를 ‘자료 부족’과 구분해 ‘모델이 답변 문장을 만들지 못했습니다’로 보인다.

- 다른 말로 묻는 24문항의 실패 3건(2026-10-07, 1회): 표의 값을 다른 말로 물은 두 문항(‘시범사업에 배정된 예산’, ‘운영비는 얼마나 썼어’)을 근거 없이 보류했고, “2025년 용역은 최종적으로 얼마로 정산됐어?”에는 자료에 없는 정산액 대신 계약금액과 정산 규정을 답했다.
- 묻는 것과 다른 내용을 답하는 경우. 초점 낱말·때·마디 검사로 줄였지만 규칙으로 알 수 있는 것만 본다.

- 초점 낱말 검사는 같은 뜻의 말 묶음(기한·마감·기일·시한, 서식·양식)과 줄인 말(계약액 ← 계약금액)만 따라간다. 그 밖의 다른 표현으로 물으면 옳은 답도 보류할 수 있다.

## 5. 하지 못한 것

1. **실제 온나라 연결** — 기관 버전·인증·검색·다운로드 사양 미확보(G0). 계획서 기준 P0 미완료.
2. **실제 기관 문서** — 실제 한글 저장 HWPX·HWP 5.0, 실제 자료의 최종 60문항, 두 번째 모델.
3. **깨끗한 PC·오프라인 설치** — Python 없는 별도 Windows PC에서의 실행과 최소 사양 측정.
4. **제3자 실행** — 개발자가 아닌 사람이 안내서만 보고 첫 업무를 수행하는 시험. 화면은 시험 코드로 눌렀고 사람이 써 본 것이 아니다.
5. **성능·효과 측정** — 장비 사양 기록, 질문 지연 p50/p95, 최대 메모리, 수작업 대비 시간·누락.
6. **라이선스 확정** — 저장소 `LICENSE`, AGPL-3.0에 따른 소스 제공 방식.
7. **원격 CI** — GitHub Actions·GitLab 설정 파일은 있으나 원격 실행 결과를 확인하지 않았다.

## 6. 코드로 이어갈 수 있는 것

- ‘지금 할 일’ 카드와 문서 화면의 온나라 공식 출처 표시, 앱 안의 수집 실행 화면, 로컬 초안과 등록본의 버전 연결.
- 문장 추출의 정밀도 올리기, 여러 문단·번호 목록·표로 적힌 절차를 단계로 읽기.
- 묻는 것과 다른 답을 걸러내는 검사의 보강, 새 질문으로 다시 재기.
- 끊긴 근거 목록과 중복 후보를 사람이 고르는 화면, 복원본 판 사이의 차이 보기.
- 업무 복원본 대화상자의 시각 표기 통일(목록은 이 PC의 시각, 요약은 세계 표준시로 적힌다).
