## 3. 문서 작성 및 관리 원칙

1. **단일 현황 문서 중심 관리:** 구현이 완료된 단계별 계획서, 일자별 진행 기록, 임시 진단 로그는 상태 문서([현재 구현 및 검증 현황](현재구현_및_검증현황.md))에 결과를 흡수한 뒤 삭제·정리하여 문서 간 불일치를 방지합니다.
2. **합성 데이터 및 실환경 미확인 명시:** 기관 실문서·실제 온나라 서버가 아닌 개발 장비/합성 데이터셋에서 측정된 수치와 기능에는 항상 `"실환경 미확인"` 또는 합성 검증 조건을 명시합니다.
3. **런타임 리소스 보존:** 프롬프트 파일(`app/ai/prompts/*.md`) 및 오픈소스 라이선스 고지문(`app/licenses/texts/`)은 실행 런타임 리소스이므로 문서 정리 대상에서 제외합니다.
