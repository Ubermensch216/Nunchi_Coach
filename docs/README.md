## 3. 문서 작성 및 관리 원칙

1. **완료된 구현 계획서 정리:** 구현이 완료된 단계별 계획서, 일자별 진행 기록, 임시 진단 로그는 상태 문서([현재 구현 및 검증 현황](현재구현_및_검증현황.md))에 결과를 흡수한 뒤 정리하여 최신성 유지를 방해하지 않도록 합니다.
2. **합성 데이터 수치 명시:** 기관 실문서가 아닌 개발 장비/합성 데이터셋에서 측정된 수치에는 항상 해당 조건을 명시합니다.
3. **코드 주석 및 힌트 보존:** 기존 프롬프트 파일(`app/ai/prompts/*.md`) 및 오픈소스 라이선스 고지문(`app/licenses/texts/`)은 문서가 아닌 실행 런타임 리소스이므로 임의로 수정/삭제하지 않습니다.
