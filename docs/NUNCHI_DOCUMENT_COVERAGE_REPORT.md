# 파일 처리 범위와 누락 진단

기준일: 2026-10-10. 사용자 기관 자료는 처리하지 않았다. 이 문서는 구현한 계측과 합성
검증의 범위를 설명한다. 실제 자료원의 전수 조사율·추출 성공률을 대신하지 않는다.

## 집계 계약

`관찰한 파일 = 포함 파일 + 미지원 확장자 파일 + 제외 파일 + 접근 오류 파일`.
각 항목은 한 스캔 실행 안에서 상호 배타적이다. 제외/접근 불능 **디렉터리**는 별도 단위다.
그 안의 파일 수는 모르는 값이며 0으로 채우거나 조사율 100%로 계산하지 않는다.

`업무 배정 고유 문서 + 미배정 고유 문서 = 분류 가능 고유 문서`.
분류 가능 문서는 현재 존재하는 업무 자료원 문서 중 파싱 ok/partial이고 비어 있지 않은
본문 섹션이 있는 문서다. 노트북 업로드 자료는 업무 발견의 분모에서 제외한다.
여러 업무에 배정한 하나의 문서를 여러 번 세지 않는다.

문서 대표 임베딩 수, 부모 조각 수, 해당 모델의 부모 임베딩 수, 전체 부모 임베딩이
준비된 문서 수는 별도 지표다. 다른 모델의 벡터를 현재 모델의 완료 건수로 세지 않는다.

## 저장·조회

- `scan_runs`: 자료원별 실행, 시작·종료 시각, completed/partial/cancelled/interrupted.
- `scan_entries`: 관찰한 파일, 생략한 폴더 경계, 사유, 연결 가능한 문서 ID.
- `processing_issues`: 문서별 해시·파싱·임베딩 오류 코드와 발생 횟수. 원문을 넣지 않는다.
- `pipeline_stage_results`: 단계별 최근 처리 건수, 결과 상태, 설명과 오류.
- `core.coverage.documents/snapshot`: 현재 문서·형식·자료원별 집계 및 근거 연결 조회.
- 분석 상태 화면: 처리 범위, 부분 추출, 원본 없음, 미배정, 제외·접근 오류 항목 표시.
- `python -m app.tools.coverage`: DB를 SQLite `mode=ro`로 열어 JSON 출력. 승격하지 않는다.

과거 버전의 제외 기록은 소급 생성하지 않는다. 다음 조사 전에는 `not_recorded`로 표시한다.
디렉터리 제외 설정은 하위 파일 전수 열거를 요구하지 않는다. 명시된 범위를 보존한다.

## 추출 상태의 의미

`ok`는 파서 실행 성공이며 내용 완전성은 `unverified`이다. `partial`은 알려진 일부
추출이며 `known_partial`이다. 완전 추출 문서 수는 `null`로 출력한다.
파일별 파서 판본, 본문 글자 수, 섹션 수, parse_note/error를 함께 반환한다.
전역 상한(MAX_BYTES/MAX_CHARS/MAX_CELLS_PER_SHEET)도 제공하되 실제 생략량으로 해석하지 않는다.
모든 형식의 생략 페이지·시트·셀을 정밀 계측하는 작업은 아직 남아 있다.

## 검증 결과

- 합성 스캔: 관찰 파일 4건 = 포함 1 + 미지원 1 + 제외 2. 숨김 폴더 1개는 별도 제외.
- 접근 불능 폴더: 부분 조사로 기록하고 기존 문서를 실제 삭제로 판단하지 않음.
- 중단: 방문하지 않은 문서를 누락 원본으로 처리하지 않음.
- 변경: 크기와 수정시각을 보존한 내용 교체를 `verify_hash=True`에서 탐지.
- 복수 배정: 한 문서를 두 업무에 연결해도 배정 문서 수는 1.
- 모델 변경: 다른 모델의 벡터를 현재 모델 완료 수에 포함하지 않음.
- 재파싱 실패: 기존 본문·부모/자식 검색 조각 제거, 실패 코드 유지.
- 부모 임베딩 실패: 자식 잔여가 0이어도 준비 완료 표시를 세우지 않음.

시험: `tests/test_pipeline_coverage.py`, 기존 `tests/test_pipeline.py`,
`tests/test_refresh_integrity.py`, `tests/test_locked_files.py`.

실제/합성 형식별 집계는 진단 CLI의 `by_format`, 파일별 내역은 `documents`,
후보 판단 근거는 `classification_evidence`로 확인한다. 파일 발견, 추출, 색인,
분류 배정, 모델에 발췌를 제공한 사실은 서로 다른 상태다.

`classification_evidence_documents`와 `model_reviewed_excerpt_documents`는 배정된 업무에
현재 유효한 근거가 있는 문서를 센다. 보류 군집을 포함한 모든 모델 호출의 총 검토 문서 수가
아니며, 원문 변경·조각 삭제·모델 불일치는 현재 근거 집계에서 제외한다.
