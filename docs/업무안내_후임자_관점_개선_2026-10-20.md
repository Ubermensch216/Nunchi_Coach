# 업무 안내 문구 개선

업무 안내와 매뉴얼에서 폴더·파일 개수를 업무 개요로 제시하던 방식을 바꾸었다.
업무 개념과 담당 범위를 설명하고, 착수 시 확인할 내용, 기간, 수행 순서,
결과물·제출처, 완료 확인 방법을 안내한다.

- 행정사무감사는 지방의회의 감사와 수감기관의 자료 취합 역할을 구분한다.
- 감사 주체·대상 기관·감사 대상 기간·감사 실시 기간·담당 업무·자료 작성 기준일을
  명시한 문구는 기존 분석 경로에서 근거와 함께 추출한다.
- 해당 기관의 사실과 일반적인 준비 제안을 구분한다. 확인되지 않은 기관명,
  대상 기간, 마감일, 제출처를 일반 지식이나 파일 연도로 채우지 않는다.
- 자료에 절차가 있으면 해당 절차를 유지하고, 없으면 준비 순서를 제안한다.
  의회 측 담당 업무가 명시된 경우 의회 측 준비 순서로 안내한다.
- 사용자 보완, 항목별 근거·적용 상태, 충돌·재확인 경고, 과거 사례를 보존한다.
- 안내 화면에서도 범위·기간·절차·결과물·제출처를 두 줄로 잘라 숨기지 않는다.
- 새 범위·역할 항목은 노트북에 넣는 업무 정리본에도 포함한다.

화면 문구 변경은 재실행한 앱에서 적용된다. 기존 프로젝트의 원문에 있는 새로운
범위·역할 항목을 추출하려면 해당 자료를 다시 분석해야 한다.

일반 개념 참고: [국가법령정보센터, 지방자치법 시행령의 행정사무 감사·조사 규정](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=173505).
이 설명은 특정 기관의 감사계획이나 현재 제출기한의 근거로 사용하지 않는다.
