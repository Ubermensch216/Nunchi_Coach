# 글꼴 확대·벡터 렌더링 검토 및 적용 결과

2026-10-20 · Windows / PySide6·Qt 6.11.1

## 결론

글자 윤곽을 확대 크기에 맞춰 다시 그리는 방식은 가능하며, 앱이 사용하는 Pretendard TTF 자체가 이미 벡터 윤곽 글꼴이다. 글자를 이미지 파일로 붙여 놓은 UI가 아니다. 다만 화면에 표시한 결과와 PNG 캡처는 픽셀이므로, 작은 캡처를 이미지 뷰어에서 크게 늘리면 계단 모양도 함께 커진다. 실제 앱의 글자 크기를 키우거나 SVG 원본을 확대하는 것과 구별해야 한다.

첨부에서 관찰되는 주황·파랑 테두리는 서브픽셀 안티앨리어싱과 부합한다. 첨부만으로 확대 도구·배율까지 확정할 수는 없지만, 개발 환경의 기존 Windows 렌더링에서도 같은 현상을 재현했다.

이전 수정은 글자 크기와 굵기 체계를 정돈하고 안티앨리어싱 선호를 지정한 것이었다. 이번에는 Windows 글꼴 엔진까지 변경하고 실제 출력 픽셀로 효과를 확인했다.

## 실제 수정

- 앱 시작 시 Windows의 Qt 글꼴 엔진을 번들 **FreeType**으로 지정했다. Qt의 기본 DirectWrite 경로에서는 `NoSubpixelAntialias`를 지정해도 비교 샘플에 색 테두리가 남았다.
- 윤곽 글꼴 강제 사용(`ForceOutline`), 회색조 안티앨리어싱 요청(`PreferAntialias | NoSubpixelAntialias`), 요청 크기 우선(`PreferMatch`)을 적용했다.
- 가로 윤곽을 픽셀 격자에 강제로 맞추지 않는 수직 힌팅을 유지했다. 작은 한글의 가독성과 큰 크기 재렌더링을 함께 고려한 선택이다.
- 사용자가 명시한 Qt 플랫폼·엔진 환경변수는 보존한다. OS ClearType 설정과 설치 글꼴은 변경하지 않는다. 새 엔진은 앱을 다시 시작하면 적용된다.

주요 변경: `app/ui/text_rendering.py`, `app/main.py`, `app/ui/theme.py`.

## 비교 결과

동일한 Pretendard Bold, 24 논리 px, 흰 바탕·검은 글자의 “업무를 파악하고 월별 실적을 취합합니다”를 Windows Qt 플랫폼으로 그렸다.

| 항목 | 기존 DirectWrite 경로 | 적용한 FreeType 경로 |
|---|---:|---:|
| RGB 채널 차이가 3을 넘는 색 번짐 픽셀 | 1,578 | 0 |
| 회색조 중간 밝기로 표현한 글자 가장자리 | 비교 대상 | 확인 |
| 글꼴의 벡터 윤곽 | 있음 | 있음 |

이 수치는 위 샘플 한 장의 결과이며 모든 모니터의 주관적 선명도를 나타내는 점수는 아니다. 엔진 변경은 색 번짐과 윤곽의 거친 인상을 줄이지만, 저해상도 화면이나 확대된 PNG에서 픽셀 자체를 없애지는 못한다.

비교 PNG의 3번은 작은 기존 PNG를 3배 확대한 것이고, 4번은 같은 글꼴을 72px로 새로 그린 결과다. SVG 예시는 글자를 `<path>` 윤곽으로 저장했으며 비트맵 `<image>`를 포함하지 않는다. 브라우저에서 SVG 자체를 열어 확대하면 크기에 맞게 다시 그려진다. 앱의 모든 텍스트를 SVG 이미지로 바꾸는 작업은 필요하지 않다. 앱의 텍스트는 기존대로 Qt 레이아웃·접근성·동적 갱신 기능을 유지한다.

## 검증 범위와 사용 방법

- 별도 Windows 프로세스에서 실제 FreeType 엔진을 초기화해 24px·72px 글자가 회색조로 래스터화되는지, 중간 밝기 픽셀이 존재하는지, 한글의 벡터 윤곽이 존재하는지 검증했다.
- 합성 프로젝트 DB 사본의 업무 홈을 Windows 플랫폼의 숨겨진 위젯으로 렌더링했다. 배율 100/125/150% × 작게/보통/크게의 9개 조합에서 카드 설명의 높이와 연간일정 내부 스크롤 범위가 정상임을 확인했다.
- 실제 모니터 간 창 이동·사용자 PC의 원격 접속·돋보기 프로그램까지 검증한 것은 아니다. 이미 저장된 스크린샷의 글자는 새 엔진으로 바뀌지 않는다.

앱을 완전히 종료한 뒤 다시 실행하고, 실제 글자를 키울 때는 **설정 → 화면 → 글자 크기 → 크게**를 사용한다. 이미지 뷰어의 확대는 PNG 픽셀 확대이므로 벡터 품질을 확인하는 방법으로 적합하지 않다. SVG의 특성을 확인하려면 위 SVG 파일 자체를 브라우저에서 연다.

## 기술 근거

- [Qt QFont: outline·antialiasing·hinting 옵션](https://doc.qt.io/qt-6.11/qfont.html): 윤곽 글꼴과 회색조 요청은 지원되지만 엔진·플랫폼에 따라 적용 가능성이 다르다.
- [Qt 공식 글꼴 엔진 안내](https://www.qt.io/blog/text-improvements-in-qt-6.7): Windows에서 DirectWrite·FreeType 엔진 선택을 지원한다.
- [Qt High DPI](https://doc.qt.io/qt-6/highdpi.html): 논리 좌표와 물리 픽셀을 구분해 표시한다.
